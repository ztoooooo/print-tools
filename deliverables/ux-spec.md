# 票据打印工具 · 体验设计规范（Phase 2）

> 主题：**让「添加 → 排版 →（矫正）→ 打印」像把票据放上 A4 纸一样直接、可预期**
> 适用：Vue 3 + Element Plus + Vite · 纯前端 · 零网络 · 本地票据打印工具
> 版本：v1.0 · 体验设计师（优希）
> 交付对象：team-lead / 前端工程师（效果图与实现依据）
> 配套文件：`visual-style-guide.md`（v1.0，拟物纸张感）。本规范**不推翻任何视觉决策**，色值、字号、间距、阴影一律引用视觉规范；本文只规定「信息怎么排、操作怎么走、状态怎么说」。

---

## 0. 体验总原则（验收依据）

| # | 原则 | 一句话 | 对应 Nielsen 启发式 |
|---|------|--------|--------------------|
| U1 | **所见即所得是唯一铁律** | 预览 = 打印 = 导出 PDF，三者逐像素一致；A4 上的一切编辑装饰（角点、透视框、空轮廓、水印之外的提示）**绝不进入**打印/导出。 | 系统状态可见 |
| U2 | **状态即时可见** | 每一次操作（添加/删除/旋转/换模式/改设置）必须在 ≤100ms 内产生可见反馈：预览重绘、状态栏数字变化，二选一或同时发生。 | 系统状态可见 |
| U3 | **不阻断、可挽回** | 单个文件解析失败不阻塞其余文件；删除/清空需二次确认；替换槽位即覆盖但旧图去重记录释放（可重新添加）。 | 防错 / 用户控制与自由 |
| U4 | **说人话，不暴露技术** | 用户看到的是「复制两份双打」「2×2 网格」，不是 mode key；opencv、wasm 等技术名词只在降级提示中以「矫正功能不可用」转述。 | 系统与真实世界匹配 |
| U5 | **全程可键盘、焦点可辨认** | 所有功能可用键盘完成；焦点一律朱红描边（`--line-focus`），不依赖颜色单一通道传达信息。 | 无障碍 / 灵活高效 |

**全局铁律补充（写给前端，务必写进验收单）：**
- 打印/导出态：`box-shadow / transform / 桌面噪点 / 纸纹 / 透视覆盖层 / 空状态轮廓` 全部 `display:none 或 reset`；canvas 恒为白底 `#FFFFFF`。
- 三 Tab 数据**完全隔离**：在「发票」里操作，不得让用户误以为会影响「车票/证件」；所有跨 Tab 的批量动作只有顶栏「重置全部」一处，且文案必须写明「三个 Tab」。

## 1. 信息架构校对

### 1.1 顶层结构（已确认合理，保持不变）

```
┌─ 顶栏 48px：品牌名（左）……………… 重置全部（右）
├─ Tab 栏 44px：发票 | 车票 | 证件
├─ 主区（flex）：
│   ├─ 左侧控制面板 280px（纵向滚动）
│   └─ A4 预览桌面（flex:1，内部滚动）
└─ 底部操作栏 52px：[打印] [另存 PDF] ………… 状态栏（右对齐）
```

校对结论：顶栏→Tab→控制面板→桌面→底栏，符合「先选类型 → 再备料 → 边看边调 → 最后输出」的心智模型；主操作（打印）固定在右下角视线终点，位置合理。**仅需统一文案与分区内排序（见下）。**

### 1.2 左侧面板分区与排序（三 Tab）

排序逻辑统一为：**① 放文件的入口 → ② 已放进来的内容 → ③ 怎么排 → ④ 怎么打**。这是「备料 → 看料 → 排料 → 出料」的自然顺序，与用户任务流同向，校对通过。

#### 发票 Tab（4 分区）

| 序 | 分区标题（最终文案） | 内容 | 备注 |
|---|--------------------|------|------|
| 1 | **文件** | 上传区（点击/拖拽，多文件） | hint 实时显示当前张数 |
| 2 | **排版模式** | 2×2 可视化模式卡片（single/double/merge2/auto） | 卡片选中即时重绘 |
| 3 | **文件列表** | 序号徽章 + 文件名 + 旋转/删除；标题行右侧「清空」 | 列表可滚（建议上限高 320px），上传后用户需在此核对 |
| 4 | **打印设置** | 纸张方向 / 色彩 / 打印份数 | 全局生效，固定在面板底部 |

> ⚠️ **排序调整建议（相对当前实现）**：当前实现顺序为「上传区 → 模式 → 文件列表」。建议把 **文件列表上移到上传区正下方（①上传 ②列表 ③模式 ④设置）**。理由：文件添加后「确认文件对不对、删错的、转方向」是紧随其后的高频动作（Nielsen：识别优于回想）；而排版模式是在确认素材无误后才做的决策。若前端因改动成本希望保留现有顺序，则**最低限度**需保证上传后预览自动出现且列表项可见（不折叠），本规范对两种排序均接受，**以「上传 → 列表相邻」为首选**。

#### 车票 Tab（4 分区）

结构同发票：**文件 → 排版模式（含 grid2x2 旋转提示）→ 文件列表 → 打印设置**；排序调整建议同上。grid2x2 选中时，模式卡片下方出现 warning 浅底提示条（见 §3.2）。

#### 证件 Tab（3 分区，结构本质不同，校对通过）

| 序 | 分区标题（最终文案） | 内容 |
|---|--------------------|------|
| 1 | **证件文件** | 顶部批量上传区（按顺序填空槽）+ 4 个固定槽位卡（槽位号 + 证件类型下拉 + 自定义尺寸行 + 填充/已填态） |
| 2 | **证件排版** | 2×2 模式卡片（double-col/double-row/center/auto） |
| 3 | **打印设置** | 同全局 |

> 证件无「文件列表」分区——4 槽位本身既是内容容器又是操作对象，文件与位置合一，信息架构正确，不再另设列表。透视编辑器不在左侧面板，它**叠加在 A4 预览上**（见 §5），避免面板与桌面两处编辑同一对象造成心智分裂。

### 1.3 分区标题文案总表（直接落地）

| 位置 | 文案 |
|------|------|
| 发票/车票 上传分区 | `文件` |
| 证件 槽位分区 | `证件文件` |
| 发票/车票 模式分区 | `排版模式` |
| 证件 模式分区 | `证件排版` |
| 列表分区 | `文件列表` |
| 设置分区 | `打印设置` |
| 列表清空入口（右上，文字按钮） | `清空` |

- 标题一律使用视觉规范 section 样式（13px/600/`--ink-strong`，可选朱红竖条）。
- 不在分区标题中使用问号或动词句（用「文件」而非「添加文件」——标题标界，动作交给内部控件）。

## 2. 三 Tab 关键任务流程与即时反馈

### 2.1 发票 / 车票：标准流程

```
[添加文件]                [预览即现]              [选排版模式]              [微调（可选）]           [输出]
点击上传区 或 ──→ 解析(PDF自动拆页) ──→ A4 立即重绘 ──→ 点模式卡片 ──→ A4 重排 ──→ 旋转/删除文件 ──→ [打印]
拖入文件/拖到窗口          逐项进入列表             状态栏张数/页数更新       状态栏页数可能变化        状态栏全程同步        [另存 PDF]
```

**每一步的界面反馈（必须逐项实现）：**

| 操作 | 预览反馈 | 列表/面板反馈 | 状态栏反馈 |
|------|---------|--------------|-----------|
| 添加文件成功 | 新页插入并立即重绘；多文件时翻页工具条出现 | 新列表项带序号徽章出现；上传区 hint 张数 +N | `N 张`、`共 N 页` 更新 |
| PDF 多页 | 拆出的每一页各占列表一项（文件名 `原名#1/#2`），逐页渲染 | 解析期间有加载态（见 §4.2） | 渲染完成后页数更新 |
| 删除文件 | 该页消失；若只剩一页，翻页条隐藏；当前页码自动钳制 | 列表项移除，其后序号自动重排 | 张数、页数 −1 |
| 旋转 90° | 对应图即时旋转重绘 | 按钮文字 `旋转 90°/180°/270°/0°` 同步 | 一般不变（模式改变页数除外） |
| 切换模式 | A4 立即按新模式重排 | 模式卡片选中态切换（朱红软底+描边+对勾） | `共 N 页` 随模式变化（如 single 3 张=3 页，merge2 3 张=2 页） |
| 纸张方向 纵↔横 | A4 轮廓与内容整体重排（794×1123 ↔ 1123×794） | segmented 按钮切换 | `A4 纵向/横向` 更新 |
| 彩色↔黑白 | 预览即时去色（灰度） | segmented 切换 | `彩色/黑白` 更新 |
| 份数 ± | 不影响预览 | 数字框更新（等宽数字，不抖动） | `N 份` 更新 |
| 打印 | 调起浏览器打印对话框；取消则界面无变化 | — | 不变 |
| 另存 PDF | 导出中按钮进入短暂忙碌态；完成后浏览器下载 | 成功 Toast：`已导出 print-YYYYMMDD-HHmmss.pdf` | 不变 |

> 反馈优先级：**预览 > 状态栏**。任何情况下预览必须先反映真实结果；状态栏是摘要而非真相来源。

### 2.2 证件：含透视矫正的流程

```
[填充槽位]                  [选证件类型]            [透视矫正（可选，逐槽位）]        [排版]          [输出]
批量上传/单槽上传 ──→ 槽位显示✓+文件名 ──→ A4 出现证件图 ──→ 下拉选身份证/银行卡/ ──→ A4 尺寸变化
                                           （严格物理 mm）
                                                                   │
                          在预览上点【透视矫正】入口/自动展开 ──────┤
                                                                   ▼
                          选槽位 1–4 → 拖四角（或方向键微调）→【裁剪确认】
                                   → 矫正图替换原图、角点重置、Toast「矫正完成」
                                   → A4 以矫正后新图重绘
                                                                   │
                                              选证件排版模式 ──→ A4 重排 ──→ [打印]/[另存 PDF]
```

关键反馈补充：

| 操作 | 反馈 |
|------|------|
| 槽位填入 | 槽位卡由 dashed 空态变为 ✓（success 色）+ 文件名 + 旋转/移除；批量上传区 `已填 n / 4` 更新；预览出现该图 |
| 槽位替换（向已填槽拖新图/点选新图） | 原图即时被覆盖、`edited` 标记清为 false、角点按新图四角重置；无需确认（属同位置直接换料，且可重新上传旧图）；给 info Toast：`已替换槽位 n 的图片` |
| 清空槽位（移除） | 槽位回到 dashed 空态；预览该图消失；`已填 n / 4` −1 |
| 切换证件类型 | 预览图尺寸按预设 mm 即时变化（身份证 89.5×57.9 / 银行卡 85.6×53.98 / 户口簿 143×105 / 自定义）；超限自动等比缩小 |
| 自定义宽/高输入 | 失焦或回车后钳制到 1–300mm 并即时重绘；非法输入不崩（保持原值） |
| 裁剪确认成功 | 预览中该槽位图换成矫正结果；角点框消失回到默认四角；Toast「矫正完成」 |
| opencv 不可用 | 见 §5.4 降级：保留原图，功能仍可继续（排版/打印不阻塞） |

> **槽位 ↔ 页码联动**：在多页排版（如 auto/double-col 放不下）时，点编辑器槽位 1–4 自动翻到该槽位所在页；翻页时编辑器自动跟随该页首个槽位。此联动对用户不可见地工作，不需要额外提示，但必须避免「红点在一页、图在另一页」的错位。

## 3. 排版模式可用性说明（大白话文案库）

> 用法：卡片下方/悬浮提示使用「大白话」列；卡片名称保留短名。所有解释面向不懂印刷术语的用户。

### 3.1 发票模式

| key | 卡片名称 | 大白话解释（建议作 title/tooltip 或卡片下 caption） | 前置条件 / 提示 |
|-----|---------|---------------------------------------------------|----------------|
| `single` | 单张居中 | **一张发票一页纸，放在页面上方居中。** | 无；文件再多也每张一页 |
| `double` | 双打（复制两份） | **同一张发票在一页纸上复制两份，上下各一张**——打印一张纸就有两份一样的票据。 | 无；注意与 merge2 区分：double 是「一份变两份」，merge2 是「两张不同的拼一页」 |
| `merge2` | 上下合并两张 | **两张不同的发票上下拼在同一页纸上**，省纸；只有一张时本页就只放一张。 | ≥2 张才有合页效果；奇数张时最后一页单张，不补空白 |
| `auto` | 自动堆叠 | **能放几张放几张，从上到下自动排，满了自动换页。** | 无 |

### 3.2 车票模式

| key | 卡片名称 | 大白话解释 | 前置条件 / 提示 |
|-----|---------|-----------|----------------|
| `single` | 单张居中 | 一张车票一页纸，居中放置。 | 无 |
| `top-bottom` | 上下两联 | **两张车票上下排，一页纸打两联。** | ≥2 张；奇数张末页单张 |
| `left-right` | 左右两联 | **两张车票横着左右排，一页纸打两联。** | ≥2 张；适合窄长条车票 |
| `grid2x2` | 2×2 网格 | **四张车票排满一页（两行两列），最省纸。** | ≥2 张可见区别，满 4 张一页；**选中即出现提示（仅提示，不自动旋转）**：<br>`建议：先把车票旋转 90°，2×2 排列更整齐（需要逐张点「旋转」，不会自动旋转）` |

> grid2x2 旋转建议为 **warning 浅底提示条**（`--warning-soft` + `--warning` 字，左竖条），**不自动执行旋转、不弹确认框**——把控制权留给用户（U3）。

### 3.3 证件模式

| key | 卡片名称 | 大白话解释 | 前置条件 / 提示 |
|-----|---------|-----------|----------------|
| `double-col` | 双列 | **一页左右放两张证件**（如身份证正面在左、反面在右），按真实尺寸打印。 | 默认模式；≥2 槽填满成行 |
| `double-row` | 双行 | **一页上下放两张证件**，每张水平居中。 | ≥2 张 |
| `center` | 居中单张 | **一页只放一张，端端正正居中。** | 任意；多张时逐张分页/组页 |
| `auto` | 自动堆叠 | 多张证件从上到下自动排，满页自动换页。 | 无 |

### 3.4 模式可用性的通用规则

- **模式永不禁用**（不因文件数少而 disable 卡片）：文件少时选 merge2/grid2x2 依然合法，只是页内张数少；禁用会让用户误以为功能坏掉。空文件时模式卡片仍可见、可选，但预览为空轮廓。
- 切换模式是**可逆**的：随时点回，排版立即还原；模式选择按 Tab 分别持久化（localStorage），非法持久化值已在 store 层白名单兜底，用户无感。
- 模式图示（SVG）与文字必须表达同一含义；视觉规范 §6.4 的图示画法照此落地即可，选中卡片图示块变朱红，未选中为占位灰（透明度 0.5）。

## 4. 状态清单（含空状态文案）

### 4.1 控件状态总表

| 状态 | 视觉（引用视觉规范） | 触发场景 |
|------|--------------------|---------|
| 默认 | 卡片 `--paper-card` + 1px `--line-strong`；文字 `--ink-body` | 初始 |
| hover | 底 `--paper-hover`、描边 `--ink-placeholder`；纸面类可上浮 2px（U 形轻微） | 指针悬停；**禁止大幅变色/放大** |
| 选中 | 朱红软底 `--brand-seal-soft` + 1.5px 朱红描边 + 右上小对勾；文字朱红 `--brand-seal-deep` 600 | 模式卡片、segmented |
| 焦点（键盘） | 统一 `outline: 2px solid var(--line-focus); outline-offset: 1px`（朱红） | Tab/方向键聚焦；**所有可交互元素必须有** |
| 禁用 | 底 `--paper-inset`、字 `--ink-disabled`、图示块 `--ink-disabled`、无阴影 | 仅用于：打印/另存 PDF（无文件时）、翻页按钮（已到首/末页）、空槽位对应的编辑器槽位号 |
| 加载 | 内嵌旋转指示（沿用 Element Plus loading 即可，但主色覆盖为朱红/墨蓝）+ 文案 | PDF 解析、opencv 加载、导出中 |
| 成功 | 浅绿底/绿字 `--success(-soft)` + Toast | 导出完成、矫正完成、清空完成、槽位 ✓ |
| 失败 | 玫调赤 `--danger(-soft)` + Toast 左竖条 | 解析失败、导出失败 |

### 4.2 加载态细则（两类异步必须区分）

| 场景 | 出现位置 | 文案 | 是否阻塞 |
|------|---------|------|---------|
| **PDF 解析中** | 上传区变为「解析中…」+ 旋转指示；已解析完的页**先入列表先显示**（逐项落位） | `正在解析 文件名…（第 n / N 页）` | 不阻塞：可继续添加、可操作已出现的页 |
| **opencv 加载中**（证件 Tab 首次点裁剪时） | 裁剪确认按钮转 loading | `正在加载透视矫正组件…` | 仅该按钮等待；可取消（再点/切换焦点），其余排版/打印不受影响 |
| **导出 PDF 中** | 另存 PDF 按钮 loading + 按钮组遮罩 | `正在生成 PDF…` | 短暂阻塞该按钮，完成或失败后恢复 |

### 4.3 空状态（必须有引导，不留「白板」）

| 场景 | 图标 | 文案（最终） | 引导动作 |
|------|------|-------------|---------|
| 发票/车票 无文件，A4 空 | 桌面中央虚线 A4 轮廓（1.5px dashed `--line-strong`，内空纸图标） | 标题：`从左侧添加文件，开始排版`；副文案：`支持 PDF（自动拆页）/ JPG / PNG，可直接拖入窗口` | 点上传区/拖文件；**空轮廓本身不进打印** |
| 文件列表为空 | 28×28 线性空纸图标（`--line-strong`） | `暂无文件` | 指向上传区 |
| 证件：单个空槽位 | 槽内 dashed 区 + `+` | `点击或拖拽上传`；副文案标注当前类型尺寸，如 `身份证 89.5 × 57.9 mm` | 点击/拖入 |
| 证件：4 槽全空 | 桌面虚线 A4 轮廓 | 标题：`从左侧添加证件，按真实尺寸排版`；副文案：`支持身份证 / 银行卡 / 户口簿 / 自定义尺寸` | 填槽 |
| 证件：部分填充 | —（A4 已可见已填图） | 空槽仍标 `点击或拖拽上传`；批量区显示 `已填 3 / 4` | 继续填 |
| 模式导致页内不满（如 3 张选 grid2x2） | **不做特殊空状态**，留白纸即可（物理诚实：纸上本来就该留白） | 无 | 无 |

### 4.4 Toast / 提示文案库（逐字可用）

**去重与槽位：**

| 类型 | 文案 |
|------|------|
| warning（发票/车票重复） | `{文件名} 已存在，已跳过` |
| warning（槽位已满） | `证件槽位已满，已跳过 {文件名}` |
| warning（同文件在别的槽位） | `{文件名} 已在其它槽位中，已跳过` |
| info（拖入本槽位的就是当前图） | `{文件名} 已在该槽位，无需重复添加` |
| info（PDF 进单槽只取首页） | `{文件名} 共 {N} 页，已取第 1 页放入槽位` |
| info（替换成功） | `已替换槽位 {n} 的图片` |

**解析失败（单文件失败不阻塞，错误 Toast，玫调赤竖条）：**

| 情况 | 文案 |
|------|------|
| 类型不支持 | `{文件名} 解析失败：不支持的文件类型（仅支持 PDF / JPG / PNG）` |
| 解析无内容 | `{文件名} 解析失败：文件无内容` |
| 其他异常 | `{文件名} 解析失败：{错误信息}` |
| 批量中部分失败 | 每个失败文件各一条 Toast；成功文件照常入列，**不弹总结阻断框**。同批失败 ≥3 条时合并为一条：`{n} 个文件解析失败，其余已添加`，避免 Toast 刷屏。 |

**其他反馈：**

| 场景 | 类型 | 文案 |
|------|------|------|
| 清空当前 Tab 成功 | success | `已清空当前列表` |
| 重置全部成功 | success | `已清空所有文件（排版模式已保留）` |
| 导出成功 | success | `已导出 print-YYYYMMDD-HHmmss.pdf` |
| 导出失败 | error | `导出失败：{错误信息}` |
| 无文件点打印/导出（按钮通常禁用；兜底对话框） | info | `请先添加文件` |

### 4.5 确认对话框文案（防错 + 可逆边界）

| 动作 | 标题 | 正文 | 确认按钮 | 取消按钮 |

| 清空单 Tab 列表 | `清空文件` | `确定要清空【发票/车票/证件】中的全部文件吗？此操作可通过重新添加恢复。` | `确定清空`（warning 描边款） | `取消` |

## 5. 证件 Tab 专项交互

### 5.1 四槽位模型

- 固定 4 槽，顺序固定（槽位 1–4），**不可增删、不可拖拽换位**——位置即语义（通常 1/2 = 身份证正反），允许换位反而增加出错面。
- 每槽独立持有：证件类型预设、自定义宽高、图片、矫正标记 `edited`。

### 5.2 填充 / 替换 / 清空

| 动作 | 入口 | 行为 | 反馈 |
|------|------|------|------|
| 填充（空槽） | ① 点槽内 dashed 区选 1 个文件；② 拖 1 个文件到槽内；③ 顶部批量上传/拖多文件 | 单文件进指定槽；多文件按顺序填所有空槽 | 见 §2.2；✓ 徽章 + 文件名 |
| 替换（满槽） | 向该槽拖入新图，或点击槽位文件区的更换入口（建议文件名旁加「更换」小按钮；最低成本：直接拖拽覆盖） | 覆盖原图，释放旧图去重键，角点按新图重置，`edited=false` | info Toast `已替换槽位 {n} 的图片`；预览即时换图 |
| 清空 | 槽内「移除」按钮 | 仅清本槽，图片回 null | 槽回空态；无需确认（见 §4.5） |

> 同一文件不允许占两个槽（store 已拦截）；移除后即可再添加到任意槽。

### 5.3 四点透视编辑器

**进入：**
- 证件 Tab 至少 1 槽有图时，编辑器工具条自动出现在 A4 预览上方（`编辑槽位 [1][2][3][4] ｜ 重置角点 ｜ 裁剪确认`）；空槽位对应号码按钮禁用。
- 进入位置固定跟随当前页/当前槽，不做弹窗、不遮挡整页。

**角点拖拽（鼠标/触控板）：**
- 4 个角点：12px 朱红实心圆 + 2px 白边；hover/按下 14px；光标 `grab / grabbing`。
- 拖拽限制在图像范围内（0..width, 0..height），全局监听 `mousemove/mouseup`，移出 SVG 仍可继续拖、松手即停。
- 当前槽位透视连线为朱红 dashed；非当前槽位不显示框（避免四个槽位的框同屏打架）。被摄区域可覆 8% 朱红半透明。

**键盘微调（无障碍 + 精细操作共用）：**

| 操作 | 步长（图像像素） |
|------|----------------|
| 方向键 ←→↑↓ | **1 px** |
| Shift + 方向键 | **10 px** |

- 先点击（或 Tab 到）某角点完成「选中」，再用方向键；被选中角点可用加深/墨蓝色区分（不靠颜色唯一通道，建议同时加外圈）。
- 编辑器下方显示常驻小提示条（视觉规范 §6.10）：`方向键微调 1px · Shift+方向键 10px · Tab 可在四个角点间切换`。

**裁剪确认：**
- 实心朱红小按钮「裁剪确认」（全界面第二颗实心朱红，权重低于打印）。
- 成功：新图替换原图、角点回四角、框消失、Toast `矫正完成`；槽位标记 `edited=true`（可在槽位文件名旁出现极小标 `已矫正`，micro 字号 success 色）。
- 未调整角点直接确认：warning Toast `请先拖动角点框住证件四角`，不执行。
- **重置角点**：墨水蓝描边小按钮，角点恢复当前图四角（不撤销已完成的裁剪；裁剪完成后如需回退原图，只能重新上传——因此裁剪确认前的提示要让用户知道这是「对当前图片生效」）。

### 5.4 opencv 不可用时的降级（高风险交互，必须明确）

| 时机 | 表现 |
|------|------|
| 动态加载 opencv 失败 / 耗时过长失败 / API 不可用 | 点裁剪确认后 catch：**原图原样保留**，不产生半坏图；warning Toast（逐字）：<br>`透视矫正功能暂时不可用，已保留原图，不影响排版与打印。`<br>（技术原因如需展开，用第二行小字：组件加载失败 / 浏览器不支持 WebAssembly） |
| 后续可用性 | 槽位图、排版模式、纸张方向、打印、另存 PDF **全部继续可用**；「裁剪确认」按钮保留，允许用户重试（重新触发懒加载）；不把按钮永久禁用、不弹全屏错误。 |
| WebAssembly 根本不支持的环境 | 证件分区顶部出现一条可关闭的 info 浅底提示：`当前浏览器不支持透视矫正，可直接打印原图；如需矫正请更换现代浏览器。` 其余流程不受影响。 |

> 降级原则：**功能降级，数据不降级，任务不中断**——用户的核心目标（把证件打出来）永远可达。

## 6. 无障碍清单（a11y）

### 6.1 键盘可达

| 区域 | 要求 |
|------|------|
| Tab 顺序（全局） | 顶栏菜单/重置全部 → Tab 栏（发票/车票/证件）→ 左侧面板自上而下（上传区 → 各列表项内控件 → 模式卡片（2×2 逐格）→ 设置行）→ 预览翻页工具条 → 底部（打印 → 另存 PDF）。顺序与视觉阅读顺序一致，无焦点陷阱。 |
| 上传区 | `<label>` 包裹隐藏 input，可聚焦、Enter/Space 触发文件选择。 |
| 模式卡片 | 每张卡片可聚焦（`tabindex="0"`），←→↑↓ 在 2×2 网格内移动焦点，Enter/Space 选中；实现为 `role="radiogroup"` + `role="radio"` + `aria-checked`。 |
| 文件列表项 | 项本身不占焦点；「旋转」「删除」依次可聚焦；删除按钮聚焦时不触发任何自动行为。 |
| 证件槽位 | 槽内上传入口 → 类型下拉 →（已填）旋转/移除；4 槽顺序循环。 |
| 透视编辑器 | 工具条：槽位 segmented → 重置角点 → 裁剪确认；进入 SVG 后 **Tab 在 4 个角点间循环**，角点 `role="slider"`（或自定义 `role="button"` + `aria-label`），方向键 1px、Shift+方向键 10px 生效。 |
| 翻页 | PageUp/PageDown 在单页模式翻页（输入框聚焦时不劫持）；首页/末页按钮可聚焦。 |
| 全局快捷键 | 不注册无提示的单键快捷键，避免与读屏键冲突。 |

### 6.2 焦点可见

- 统一焦点样式：`outline: 2px solid var(--line-focus)（#C0392B）; outline-offset: 1px; border-radius` 跟随控件。
- **禁止 `outline:none` 后不补样式**；浏览器/系统开启「高对比度」模式时，焦点环与选中态仍须可辨（此时可加系统色描边兜底）。
- 鼠标点击操作不保留焦点环（避免点击后红框常驻），键盘操作必保留——用 `:focus-visible` 实现。

### 6.3 对比度与「不靠颜色单通道」

- 直接沿用视觉规范已达标数值：正文/标题对面板 ≥9:1、次要文字 ≥4.8:1、功能色浅底深字 ≥4.5:1。
- `--ink-placeholder`（≈2.6:1）**只用于装饰性占位**，凡承载信息的文字（如「已填 3/4」）必须使用 ≥4.5:1 的 `--ink-secondary`。
- 选中态 = 颜色 + 描边 + 对勾，三通道冗余；成功/失败 = 色条 + 图标 + 文案，色盲用户可辨识。
- 黑白模式（打印设置）是用户主动选择的输出效果，不属于无障碍缺陷；但**界面自身**在任何设置下文字对比度不降低。

### 6.4 图标按钮 aria-label / title 文案

| 控件 | `aria-label`（读屏） | 可见 title（悬停） |
|------|---------------------|-------------------|
| 列表旋转按钮 | `顺时针旋转第 {n} 个文件 90 度，当前 {deg} 度` | `顺时针旋转 90°（当前 {deg}°）` |
| 列表删除按钮 | `删除第 {n} 个文件：{文件名}` | `删除该文件` |
| 槽位上传入口 | `为槽位 {n} 上传证件图片（当前类型：身份证 89.5×57.9mm）` | — |
| 槽位旋转 | `将槽位 {n} 的证件旋转 90 度，当前 {deg} 度` | `顺时针旋转 90°（当前 {deg}°）` |
| 槽位移除 | `移除槽位 {n} 的图片：{文件名}` | `移除该槽位图片（也可直接拖新图替换）` |
| 透视角点 ×4 | `{左上/右上/右下/左下}角点，当前位置 x{px} y{px}，方向键微调` | — |
| 翻页：首页/上一页/下一页/末页 | 同名中文 | 同名 |
| 页码输入 | `页码，共 {N} 页` | — |
| 模式卡片 | `排版模式：{名称}。{大白话解释}` + `aria-checked` | 大白话解释 |
| 品牌小记号 | `本地票据打印工具`（装饰性图标可 `aria-hidden`） | — |

- 纯装饰 SVG 一律 `aria-hidden="true"`；有文字的按钮不再重复 aria-label，避免读两遍。
- segmented 组（纸张方向/色彩/槽位）用 `role="group"` + 组名（如 `aria-label="纸张方向"`）。

### 6.5 点击 / 拖拽目标尺寸

| 对象 | 最小尺寸 | 说明 |
|------|---------|------|
| 常规按钮 | 高 32（视觉规范） | 满足 ≥24px 基线 |
| 列表/槽位内小按钮 | 视觉高 24–26，**触控环境整体放大至 ≥32 高、间距 ≥4**（指针为粗指针时通过 CSS `@media (pointer: coarse)` 切换） | — |
| 透视角点 | 视觉 12–14px，**热区扩大到 ≥24×24**（用透明 padding/伪元素扩展，视觉点保持小而准） | 精细拖拽必须兼顾易抓取 |
| 模式卡片 | 整卡可点，约 64 高 | 远超最小值 |
| 上传/槽位 dashed 区 | 整区可点（dropzone 全高） | — |
| 相邻可点元素间距 | ≥4（防误触，触控建议 ≥8） | — |

### 6.6 动效与读屏公告

- 所有非必要动效响应 `prefers-reduced-motion`：关闭上移/淡入/纸面上浮，保留状态瞬切。
- 状态栏数字变化**不**逐条 live 公告（会刷屏）；但**解析失败、矫正完成、导出完成**三类结果通过 Toast 即时反馈，Toast 容器加 `aria-live="polite"`。
- 切换 Tab 后焦点处理：保留在 Tab 本身（不把焦点扔进面板），符合预期。

## 7. 响应式与窗口缩放策略

### 7.1 断点与布局策略

| 窗口宽度 | 策略 |
|---------|------|
| **≥ 1024px（推荐/默认）** | 左面板 280px 固定 + 桌面自适应；A4 以默认档（0.65）展示，整页可见。 |
| **768 – 1023px** | 左面板可收窄至 **240px**（最小不低于 220），模式卡片仍保 2×2；预览默认降到「适应窗口」档，优先**看全整页**。 |
| **640 – 767px** | 左面板提供**折叠/展开**：默认收成 48px 竖条（只留「展开面板」按钮），展开时覆盖在桌面之上（浮层，带遮罩），避免挤压 A4；底部按钮与状态栏换行不拥挤——状态栏可缩为图标+数字。 |
| **< 640px（不推荐但可用）** | 同上，面板浮层化；底栏按钮缩高 32、状态栏只显示关键两项（`N 份 · 共 N 页`），其余进「更多」。 |

- **硬性最小值**：应用内容区最小可用宽度 **360px**；低于此宽度出现横向滚动而非控件堆叠破碎。
- 左面板与桌面**不做上下堆叠**（打印工具必须同屏「边控边看」，上下堆叠会破坏 U1 的可信感）；窄屏以「面板浮层化」代替堆叠。

### 7.2 A4 预览缩放

原则：**默认看全整页；放大只用于检查细节；缩放不改变打印结果。**

| 档位 | 缩放（相对 96dpi A4 原尺寸 794×1123） | 用途 |
|------|--------------------------------------|------|
| 适应窗口（默认，auto-fit） | 动态计算：`min((容器宽-48)/A4宽, (容器高-48)/A4高)`，保证四周边距 ≥24 | 首选；窗口缩放时自动重算 |
| 50% | 约 397×562 | 小窗口 |
| 65%（当前实现默认值） | 约 516×730 | 常规桌面 |
| 75% | 约 596×842 | 检查文字 |
| 100%（实际大小） | 794×1123 | 1:1 核对，超出则滚动 |

- 切换纸张方向、拖动窗口时：若用户未手动选档，保持「适应窗口」自动重算；一旦手动选档则尊重用户选择（滚动查看），并在翻页条显示当前百分比 + 「适应窗口」复位按钮。
- 多页/连续滚动：横向仍以整页宽度可见为准，纵向自然滚动，页间距 32。
- **缩放仅影响屏幕显示**：打印与导出永远使用 794×1123（横向 1123×794）真实像素，缩放档不写入输出。

### 7.3 高风险交互与降级（汇总）

| 风险点 | 降级方案 |
|--------|---------|
| opencv 加载/执行失败 | 保留原图 + warning Toast，排版/打印/导出不中断（§5.4） |
| PDF 超大/多页解析卡顿 | 逐页解析逐页落位，已完成页先用；不整体阻塞 |
| 窗口过窄 | 面板浮层化，保 A4 同屏；不上下堆叠 |
| 浏览器不支持 WASM | info 提示 + 原图直打路径 |
| 打印态装饰误入 | 打印 CSS 强制清除全部装饰与覆盖层（U1 验收必查） |
| localStorage 损坏 | 模式/设置白名单 + 默认兜底（已在 store 层实现） |

### 8.4 三图统一绘制约束

- 色值、字号、圆角、投影、间距**逐项取自视觉规范**，不得引入规范外颜色（尤其不得退回 Element Plus 默认亮蓝）。
- 纸面永远是全界面最亮；朱红仅出现在：品牌记号、活动 Tab 指示、选中卡片描边/对勾、角点、裁剪确认、打印按钮。

- 建议画布比例按 1440×900 视口绘制，保证三图横向密度一致、可直接对比。
- 装饰（角点/虚线框/空轮廓）在图中可出现，但请在交付说明中标注「仅预览，不进打印/导出」，防止前端误画进输出层。
