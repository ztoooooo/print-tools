# 票据打印（local-print-tool）

一款 **纯前端、本地运行、离线可用** 的票据 / 证件排版打印工具。支持 PDF、JPG、PNG，
把上传的发票、车票、证件按多种模式排版到 A4 纸上，所见即所得地打印或导出 PDF。

> 所有文件只存在于浏览器内存中，**不上传任何服务器**，断网也能用。

## 功能特性

- **三个独立工作区**：发票、车票、证件，文件互不干扰。
- **多格式支持**：PDF 自动逐页拆分，JPG / PNG 直接导入。
- **多种排版模式**：单张居中、双打（复制两份）、上下合并、左右两联、2×2 网格、自动堆叠与分页。
- **高清渲染**：图片保留原始分辨率，页面按 300 DPI 合成，预览 / 打印 / 导出均清晰锐利。
- **自定义水印**：可配置水印内容、应用范围、字号、不透明度与颜色。
- **拖拽排序**：文件列表内拖动即可调整顺序，预览与导出顺序实时同步。
- **透视矫正**：证件支持四角透视矫正（基于 OpenCV，懒加载，本地完成）。
- **所见即所得**：预览 = 打印 = 导出 PDF，共用同一套布局真源。
- **偏好持久化**：纸张方向、彩色 / 黑白、打印份数等设置自动记住。

## 技术栈

| 类别 | 技术 |
| --- | --- |
| 框架 | Vue 3（`<script setup>`）+ Vite 5 + TypeScript |
| 状态管理 | Pinia |
| UI 组件 | Element Plus |
| PDF 解析 / 导出 | pdfjs-dist / pdf-lib |
| 图像处理 | @techstark/opencv-js（WASM，懒加载） |
| 样式 | SCSS |

## 快速开始

### 环境要求

- Node.js 18 及以上（推荐 20+）
- npm（或 pnpm / yarn）

### 安装与运行

```bash
# 安装依赖
npm install

# 启动开发服务器（默认 http://127.0.0.1:5173）
npm run dev

# 生产构建（含类型检查）
npm run build

# 本地预览生产构建
npm run preview
```

## 使用说明

1. 选择顶部的「发票 / 车票 / 证件」工作区。
2. 拖入或点击上传 PDF / JPG / PNG 文件。
3. 在「文件列表」中拖动调整顺序，或对单张旋转、删除。
4. 在「排版模式」中选择需要的布局。
5. 在「打印设置」中调整纸张方向、色彩与份数；在右上角「设置」中配置水印。
6. 点击底部「打印」直接输出，或「另存 PDF」导出文件。

## 目录结构

```
├─ src/
│  ├─ components/      # 界面组件（顶部菜单、左面板、预览画布、弹窗、透视编辑器等）
│  ├─ stores/          # Pinia 状态（文件、布局、界面、设置、透视角点）
│  ├─ utils/           # 文件解析、画布绘制、PDF 导出、OpenCV 透视矫正
│  ├─ styles/          # 全局样式与打印规则
│  ├─ types.ts         # 全局类型定义
│  ├─ units.ts         # 常量与 mm/px 换算（唯一常量源）
│  └─ main.ts          # 应用入口
├─ index.html
├─ vite.config.ts
└─ package.json
```

## 隐私与安全

- **零后端、零上传**：文件不会离开你的设备。
- **无账号、无追踪、无统计**。
- 刷新或关闭页面后，已上传的文件会清空，请及时打印或导出 PDF 保存。
